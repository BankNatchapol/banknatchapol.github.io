## Overview

**ml-decoder** is a graph neural network (GNN) decoder for the surface code that learns to correct Pauli errors directly from syndrome measurements. Standard MWPM performs optimally only under i.i.d. depolarising noise — under correlated noise from real hardware (leakage, crosstalk, structured two-qubit errors) it degrades significantly. A learned decoder can capture these correlations without explicit noise-model engineering.

## How It Works

Each syndrome round is a graph: nodes are stabiliser detectors that fired, edges connect adjacent detectors weighted by local error probability. A stack of GraphSAGE-style message-passing layers with layer normalisation and residual connections computes node embeddings encoding global syndrome context. The final layer predicts per-edge error probability; a greedy pass selects the correction.

Training data is generated on-device by `surfsim` at ~10⁷ labelled samples/second on an A100, using binary cross-entropy loss with AdamW (lr=3×10⁻⁴, cosine decay, 200k steps).

## Results

| Error rate | GNN logical error rate | MWPM logical error rate |
|---|---|---|
| p = 0.5% | 8×10⁻⁴ per round | 1.1×10⁻³ per round |
| p = 1.0% | 6.2×10⁻³ per round | 9.8×10⁻³ per round |

- GPU inference under **10 µs per sample** at batch size 1024
