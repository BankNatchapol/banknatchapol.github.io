## Overview

**scholar-rag** is a retrieval-augmented generation (RAG) assistant that lets researchers query the full quant-ph arXiv corpus in natural language. The quantum information literature now spans over 60 000 papers, and keeping up with the latest results on any given topic — say, decoder thresholds under circuit-level noise, or recent progress on cat qubits — requires either exhaustive manual search or reliance on general-purpose search engines that have no awareness of domain semantics. `scholar-rag` closes that gap by combining dense semantic retrieval with a generative model that synthesises answers grounded in actual paper text.

## Ingestion Pipeline

Papers are ingested from the arXiv bulk S3 export and processed through a multi-stage pipeline. PDFs are converted to structured text using a layout-aware parser that preserves equation blocks as LaTeX source rather than attempting OCR-to-Unicode conversion, which degrades retrieval quality for mathematical content. Each paper is split into overlapping chunks of ~400 tokens with a 50-token stride; equation-heavy paragraphs are kept intact. Metadata (title, authors, abstract, primary category, submission date) is stored in a lightweight SQLite index that the retriever consults for filtering (e.g., "papers from 2024 on fault-tolerant quantum computing").

## Embedding and Retrieval

Chunks are embedded using a fine-tuned variant of a sentence-transformer model, adapted to quant-ph vocabulary by continued pre-training on 20 k abstract/conclusion pairs. Embeddings are stored in a FAISS flat index (inner product, with L2-normalised vectors equivalent to cosine similarity). At query time the user's natural-language question is embedded with the same model; the top-k=20 chunks are retrieved and re-ranked using a cross-encoder to filter out false positives. The final answer is generated by a Claude API call with the top-5 chunks as context, along with instructions to cite each claim by paper title and arXiv ID.

## Usage

The assistant is available as a command-line tool (`scholar-rag query "your question here"`) and as a minimal web interface. Both return answers with inline citations that link directly to the arXiv abstract page, enabling quick verification. A curated demo query set covering common quant-ph topics is included in the repository to serve as a non-regression benchmark as the model and index are updated.
