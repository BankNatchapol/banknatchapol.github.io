## Overview

**DQI-Circuit** is an open-source quantum-circuit implementation of **Decoded Quantum Interferometry (DQI)**, developed alongside the paper [*Quantum Circuit Design for Decoded Quantum Interferometry*](https://arxiv.org/abs/2504.18334) (arXiv:2504.18334).

DQI was originally introduced as a quantum algorithm that uses interferometry and decoding to approach structured combinatorial optimization problems. Instead of directly searching over the optimization landscape, DQI reduces the problem to a decoding task, where practical decoders such as belief propagation can be applied.

Prior DQI work was mainly theoretical and provided only high-level circuit sketches. This repository addresses that gap by giving an explicit, end-to-end circuit implementation of the DQI pipeline, including state preparation, constraint encoding, coherent decoding, postselection, Hadamard transformation, measurement, simulation, and resource estimation.

## Project Goals

The goal of this project is to make DQI executable and analyzable at the quantum-circuit level.

This includes:

1. Defining the full DQI circuit pipeline step by step
2. Implementing the main circuit components required for DQI
3. Designing coherent quantum decoder circuits
4. Simulating small DQI instances to validate the construction
5. Estimating circuit resources such as qubit count, gate count, and depth

The implemented DQI workflow follows the full algorithmic structure:

1. **Error register preparation**
   Initializes the error register used to represent candidate error patterns.

2. **Unary amplitude encoding**
   Encodes the polynomial or weight-dependent amplitudes into the quantum state.

3. **Dicke state preparation**
   Prepares fixed-Hamming-weight superpositions required by the DQI construction.

4. **Phase encoding**
   Encodes objective-function information into the phase of the quantum state.

5. **Constraint encoding**
   Computes the syndrome information using the parity-check structure.

6. **Coherent decoding and uncomputation**
   Applies a reversible decoder to map syndrome information back to an error estimate and uncomputes the error register in superposition.

7. **Postselection and Hadamard transform**
   Postselects the required register state, applies the Hadamard transform, and measures the final output distribution.

## Quantum Decoder Circuits

A central contribution of this project is the design and implementation of quantum decoder circuits for DQI.

The repository includes three decoder approaches:

**Lookup-table decoder**
A direct syndrome-to-error decoder based on a precomputed table. This is useful for small instances and serves as a baseline decoder for validating the circuit construction.

**Reversible Gauss-Jordan Elimination (GJE) decoder**
A deterministic algebraic decoder that performs reversible row-reduction-style operations to recover an error estimate from the syndrome. This provides a structured circuit implementation of the decoding step.

**BPQM-based syndrome decoder**
A coherent decoder inspired by Belief Propagation Quantum Matching (BPQM). This implements message-passing-style decoding at the circuit level and connects DQI with quantum message-passing decoder design.

## Implementation

The codebase implements the DQI circuit components and decoder circuits in a modular way, allowing each stage of the algorithm to be constructed, inspected, simulated, and benchmarked.

Implemented components include:

* Unary amplitude encoding
* Dicke state preparation
* Phase encoding
* Constraint encoding
* Lookup-table decoding
* Reversible GJE decoding
* BPQM-based syndrome decoding
* Hadamard transform and measurement
* Circuit-level resource estimation

The repository is intended to serve both as an implementation of the paper and as a reference codebase for future DQI circuit experiments.

## Resource Estimation

The project includes resource-estimation tools for analyzing the cost of DQI circuit components.

The reported metrics include:

* Number of qubits
* Gate count
* Circuit depth
* Decoder-specific circuit cost
* Scaling with matrix size
* Scaling with polynomial degree

In the thesis setting, the matrix size represents the number of optimization variables and constraints, while the polynomial degree is a chosen parameter of the DQI construction.

## Simulation Results

Small-instance simulations are included to validate the DQI circuit construction.

The simulations compare the measured DQI output distribution with the objective-value landscape. This helps verify whether the circuit assigns higher probability to solutions with favorable objective values after postselection and measurement.

## Contributions

This repository contributes:

1. An explicit end-to-end circuit definition for Decoded Quantum Interferometry
2. Open-source implementation of the DQI circuit pipeline
3. Circuit-level implementations of lookup-table, GJE, and BPQM-based decoders
4. Simulation results on small DQI instances
5. Resource estimation for major DQI circuit components
